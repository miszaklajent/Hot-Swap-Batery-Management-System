# Jak używać symulacji?

1. otworzyć `variable_generator.mlx`
2. zmienić ustawienia w zależności od wybranej konfiguracji
   - moc (P)
   - stany baterii (bat_x)
   - przedmiot symulacji (SIMULATION_MODE) wybierając odpowiedni numerek z opisanych
   - czasy przełączeń (opcjonalnie)
3. uruchomić skrypt
4. otworzyć `dual_module.slx` (powinny pojawić się automatycznie 3 okna z przebiegami)
5. uruchomić symulacje
